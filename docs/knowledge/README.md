## 使用说明

- 检索优先匹配带 **加粗** 的数字规则，确保与系统真实行为一致。
- 涉及“不能办/不代答”的场景，以 knowledge-boundaries.md 为引导依据。
- 产品具体收益率以产品页实时展示为准，知识库只讲规则不讲当前利率。
- ★**能力边界（2026-10-02 事实核查后补）**：**卡片状态（冻结 / 挂失 / 注销）只约束"卡片业务"本身，
  不拦截该账户的资金收付**。因此**禁止**把"冻结卡片"写成可阻断资金流出、可防盗刷、可拦代扣的动作
  （见 `account-security.md` 第四节、`knowledge-boundaries.md` 第二/四节、`subscription-faq.md` 第四节）。
  资金拦截的实际来源是**身份核验（支付密码 + 验证码）与手机绑定闸门**。
- ★ 修改上述任一文档的"规则类"表述后，除本索引重建外，还需重建 RAG 检索索引
  （`utils.knowledge.rebuild()`，管理端「重建索引」同一入口），否则 Agent 仍检索到旧内容。
